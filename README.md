# OCRテキスト検索ハイライター

OCRで読み取り済みの長文テキストに対し、検索語（クエリ）を入力すると、表記類似と意味類似でトークンをグラデーションハイライト表示するローカルアプリケーションです。

## 機能

- **表記類似検索**: rapidfuzzを使用した文字列類似度による検索
- **意味類似検索**: sentence-transformersを使用した埋め込みベクトルによる意味類似検索
- **グラデーションハイライト**: 類似度に応じて色の濃淡が変わるハイライト表示
- **キャッシュ機能**: テキストが変わらない限り、トークン化と埋め込み計算の結果を再利用
- **日本語対応**: fugashiを使用した単語単位の日本語トークン分割に対応（fugashiが利用できない場合は簡易版を使用）

## セットアップ

### 前提条件

- Python 3.8以上
- pip（Pythonパッケージマネージャー）

### 1. リポジトリのクローンまたはダウンロード

```bash
# プロジェクトディレクトリに移動
cd ocr_search_highlighter
```

### 2. 仮想環境の作成と有効化

```bash
# 仮想環境を作成
python -m venv venv

# 仮想環境を有効化
# macOS/Linux:
source venv/bin/activate
# Windows:
# venv\Scripts\activate
```

仮想環境が有効化されると、プロンプトの前に `(venv)` が表示されます。

### 3. fugashiのシステム依存関係のインストール（単語単位トークン化を使用する場合）

**重要**: 単語単位のトークン化を使用するには、システムレベルでMeCabをインストールする必要があります。MeCabがインストールされていない場合、アプリケーションは簡易版トークン化（文字種ごとの区分）で動作します。

### 4. Python依存パッケージのインストール

```bash
# 仮想環境が有効化されていることを確認（プロンプトに (venv) が表示されているはず）

# 依存パッケージをインストール
pip install -r requirements.txt
```

**注意事項**:

- fugashiのシステム依存関係（MeCab）がインストールされていない場合、`pip install fugashi`は失敗する可能性があります。しかし、アプリケーションは簡易版トークン化で動作します。
- MeCabがインストールされているのにfugashiのインストールに失敗する場合、MeCabの設定ファイルのパスが標準でない可能性があります。その場合は、環境変数`MECABRC`にMeCabの設定ファイルのパスを設定してください。

#### インストールの確認（オプション）

```bash
# 主要なパッケージがインストールされているか確認
python -c "import streamlit; import rapidfuzz; import sentence_transformers; print('OK')"
```

### 5. fugashiの動作確認（オプション）

単語単位のトークン化が動作するか確認したい場合：

```bash
python -c "from src.tokenize import tokenize; result = tokenize('人工知能技術の発展について'); print(f'Tokens: {result}')"
```

- fugashiが動作している場合: `['人工', '知能', '技術', 'の', '発展', 'について']` のように単語単位で分割されます
- 簡易版トークン化の場合: `['人工知能技術の発展について']` のように1つのトークンになります

### 6. 初回起動時のモデルダウンロード

初回起動時に、sentence-transformersが使用する多言語モデル（`intfloat/multilingual-e5-small`）が自動的にダウンロードされます。
ダウンロードは数分かかる場合がありますが、2回目以降はキャッシュから読み込まれるため高速に動作します。

**インターネット接続が必要です。** 初回起動時のみモデルのダウンロードが行われます。

## 起動方法

### 事前確認

1. 仮想環境が有効化されていることを確認（プロンプトに `(venv)` が表示されているはず）
2. プロジェクトのルートディレクトリ（`app.py`があるディレクトリ）にいることを確認

### 起動コマンド

```bash
streamlit run app.py
```

ブラウザが自動的に開き、アプリケーションが表示されます。開かない場合は、コンソールに表示されるURLをブラウザで開いてください。

### トラブルシューティング

**「ModuleNotFoundError」が発生する場合**:
- 仮想環境が有効化されているか確認してください
- `pip install -r requirements.txt` を再実行してください

**fugashiのエラーが表示されるが、アプリが動作する場合**:
- 簡易版トークン化が使用されています（問題ありません）
- 単語単位のトークン化を使用したい場合は、MeCabのインストールを確認してください

**ポートが既に使用されている場合**:
```bash
# 別のポートを指定
streamlit run app.py --server.port 8502
```

## 使い方

1. **OCRテキスト入力**: 左側のテキストエリアに検索対象のテキストを入力または貼り付け
2. **検索クエリ入力**: 右上の検索ボックスに検索語を入力
3. **設定調整**: 左側のサイドバーで以下を調整
   - 表記類似/意味類似の使用有無
   - 閾値入力方法（自動設定/手動設定）
     - **自動設定**: 上位何単語をハイライトするかを指定（同じ単語の複数出現は1回としてカウント）
     - **手動設定**: スライダーまたは手入力で閾値を直接指定
   - 表記類似しきい値（0〜1）
   - 意味類似しきい値（0〜1）
   - 除外する単語リスト（記号や特定の単語を除外可能）
   - 結果表示設定
     - 類似度を表示：各トークンの下にスコアを表示
     - 上位単語を表示：スコア順に全単語をテーブル表示
4. **結果確認**: ハイライトされたテキストが下部に表示されます

## ハイライト色

- **表記類似**: 黄色系（`rgba(255, 235, 59, alpha)`）
- **意味類似**: 水色系（`rgba(64, 224, 208, alpha)`）
- **両方**: 混色

類似度が高いほど色が濃く（alpha値が大きくなり）表示されます。

## 主要パラメータ

### 閾値入力方法

- **自動設定**: 上位何単語をハイライトするかを指定します。同じ単語が複数回出現している場合、1回としてカウントされます。
  - デフォルト: 上位10単語
- **手動設定**: スライダーまたは手入力で閾値を直接指定します。

### 表記類似しきい値（0〜1）
- 文字列類似度の最小値。この値以上のトークンがハイライトされます
- デフォルト（自動設定時）: 上位n単語のスコアに基づいて自動計算
- デフォルト（手動設定時）: 0.3（OCR誤りを考慮して低めに設定）
- 高いほど厳密な一致に近いトークンのみハイライト

### 意味類似しきい値（0〜1）
- コサイン類似度の最小値。この値以上のトークンがハイライトされます
- デフォルト（自動設定時）: 上位n単語のスコアに基づいて自動計算
- デフォルト（手動設定時）: 0.75（誤検出を避けるため高めに設定）
- 高いほど意味が近いトークンのみハイライト

### 除外する単語リスト
- 類似度計算から除外する単語を指定できます
- デフォルトで記号（、。など）は自動的に除外されます
- カスタム除外単語を追加・削除できます

## 技術スタック

- **UI**: Streamlit
- **文字列類似**: rapidfuzz
- **意味類似**: sentence-transformers（`intfloat/multilingual-e5-small`）
- **トークン化**: fugashi（MeCabのPythonラッパー、単語単位分割用）
- **数値計算**: numpy
- **データ処理**: pandas
- **深層学習フレームワーク**: torch（sentence-transformersの依存）
